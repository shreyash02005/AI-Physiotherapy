###To run the AI Physio Copilot project on your local machine###
1. Install Dependencies
Open your terminal in the project root directory (AI Physical therapy) and run:

npm install

2. Start the Development Server
Launch the local development environment:

npm run dev

3. Open the Application
Once the server is running, open your browser and navigate to the URL shown in the terminal
